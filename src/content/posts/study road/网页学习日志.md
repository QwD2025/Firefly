## form input label
- input里的type属性
	text 文本
	password 密码
	checkbox 复选框
	radio 单选框
	submit 提交
- form提交数据到服务器
	action 服务器地址

	get 会被缓存，数据小
	post 无缓存，数据无限制，不能收藏
- label 点击label文字，自动聚焦对应表单组件，复选框单选框等
```

    <div>
        <label for="password">密码：</label>
        <input type="password" id="password" name="password" required>
    </div>
    <button type="submit">登录</button>
</form>
```

# FLEX布局
- display：flex
两条轴线：main axis和cross axis
- flex-direction 主轴方向，默认row，左右排列，column竖向排列

**justify-content**控制item在主轴的位置
- first end center
- space-between 两侧贴边，均匀分布
**align-items**控制item在交叉轴的位置

- gap控制flex间距
- flex-wrap：wrap响应式布局，nowrap不响应
- align-content：控制响应式布局下行与行的间距（一行是一个队伍，而这个是控制队伍在哪）
- 额外：
display：block 独占一行，宽度默认100%
## 响应式调节布局大小
应用在容器内项目上，1与0是开关，增大1控制增长收缩速度（权重）
- flex-shrink，控制元素会不会随着容器大小收缩，默认收缩
- flex-grow，元素默认增长填满可用空间
- max-width和min-width控制最大最小长度
- align-self，覆盖整体，对单个元素进行控制位置
技巧性：
制作导航栏时，想要把logo放到最左侧，其他导航放到最右侧，只需要把
logo属性，margin-right：auto
整体 justify-content：flex-end

# 定位与层级
## position
- relative 一般作为absolute的锚点容器，元素依然占着原来的空间，只是视觉上移动了位置
- absolute 绝对定位，脱离文档流，元素不占空间，参照物是最近设置的父元素，会覆盖其他元素，会随页面滚动
- fixed 相对于浏览器窗口，固定不动
- 经典组合：
```
html
<div class="parent">
    <div class="child">角标</div>
</div>

css
.parent {
    position: relative;   /* 父容器 */
    width: 200px;
    height: 200px;
    background: #f0f0f0;
}

.child {
    position: absolute;   /* 子元素 */
    top: 10px;
    right: 10px;
    background: red;
    color: white;
    padding: 4px 12px;
    border-radius: 20px;
    font-size: 12px;
}
```
absolute绝对，但事实上它是个相对relative的属性

# 过渡CSS Transitions和动画CSS Animations
## css过渡
将属性值的瞬时变化，转变成一个持续一段时间的平滑过程，有明确触发条件，并且只在两个状态之间切换的动画
```
transition-property  用于指定对那些属性应用动画效果
-duration  用于指定动画时间
-timing-function  用于设置速度  
ease慢快慢 ease-in慢快 ease-out快慢 ease-in-out快慢快 linear恒速
-delay 延迟
可以简写 transition：xxx xxx xxx
```
## css动画
定义关键帧来实现控制，无需交互，自动播放
```
@keyframes 定义关键帧
animation-name 指定元素
-duration 持续时间
-timing-function  用于设置速度
-delay 延迟
-iteration-count 
用于设置动画播放多少次 可以设置数字，也可以设置infinite永远播放下去
-direction 从头到尾还是从尾到头 alternate先正后反
-fill-mode none保持原型，forwards保持结束状态
-play-state 控制动画播放还是暂停

@keyframes spin{
0%{
}
100%{
}
}
```
